# Review records

Source admission records use `<catalog-id>.json` (including the pinned GRO.data
identity). They retain the decision, evidence scope and original reviewer/date.
They do not certify every future use, annotation correctness or independence.

`metadata/<catalog-id>.json` records strictly bounded editorial corrections to
existing records. Both previous and final object fingerprints are required. These
records cannot add sources, change source terms or scientific admission, expand
execution requirements, or establish new positive task support. See
[the contribution process](../CONTRIBUTING.md) and
[current source reconciliation](../docs/reviews/SOURCE-CONTENT.md).
