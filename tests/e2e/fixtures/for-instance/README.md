# Synthetic FOR-instance kernel fixture

A self-contained synthetic "reviewed release" used by `tests/e2e/kernel.spec.js`
to run the real audited preparation kernel end to end inside the pinned Pyodide
runtime, without the 1.6 GB provider archive.

- `plot.las` — deterministic point-format-6 LAS (3,000 points, classes 0-6,
  extra `treeID` dimension), generated by `generate.py`.
- `source-lock.json` — synthetic release lock whose single plot entry carries
  the real SHA256, size, point count, scales, offsets and class counts of
  `plot.las`. The kernel's cryptographic source admission is therefore genuinely
  exercised; only the inputs are synthetic.
- `policy.json` — byte copy of the audited `scripts/for_instance/policy.json`.
- `package-lock.json` — pins `prepare.py` and `requirements.txt` at their
  audited bytes (the browser test fetches them from the served audited package
  at runtime, so the fixture executes the audited policy code) plus the two
  synthetic files above.

The synthetic release markers (`download_sha256`, `provider_checksum`) identify
the fixture, never the real Zenodo release. Regenerate everything with:

    .venv/bin/python tests/e2e/fixtures/for-instance/generate.py
